# Goal：完成固定方法的正式验证与论文证据
协议：focused-maintenance-v4-20261015；执行修订：execution-ready-r2-freeze。算法起点仍为 v13，不因此命名新算法。

## 总目标
以现有 v13 Coalescing 为核心完成固定范围的 Agent Memory Maintenance 正式验证与论文证据。先按阶段复用已有合法结果，只补必要的 Notes 规则修正、Source-only 一致性及 Raw RAG/RAG+Notes 更新接口和维护数据。必要正确性、公平性与真实更新查询检查通过后冻结实现、模型、Reader、评分和数据清单，直接完成完整 Small 历史库上的固定维护实验、核心消融、连续成本、质量分项、必要重复及正文/复现交付。可选工程优化默认跳过，本轮全程最多两个主要候选，必须在正式冻结前小范围配对验证且不延误主线；不以优于 Source-only 或所有 baseline 作为启动或完成条件。依据完整可追溯结果判断成本—质量价值：有支持则写相应论文主张，无独特优势则完整保存负结果、原因与贡献不足的结论，完成本轮既定实验并结束，不无限寻找 trick。

## 范围与判断
- 整体 Methodology、baseline 和主指标已固定；现有方法内的必要实现修复、证据组织、索引与回退调整允许继续。一次一个主要候选、一至两个因素，立即实测。
- Ours 从已验证 v13 source_coalesced 核心出发，关闭“完整源行不在笔记中即复用”追加启发式。共同合法缓存、必要 Notes 生成及回退对所有适用方法一致。
- Source-only 不是 Raw RAG：共享同一初始 AgentRunbook 记忆，保留未受影响 Event/Notes，可正常检索更新后的 Raw State，只不维护受影响 Event 的当前证据。
- B3 是当前 AgentRunbook-R 的强维护适配，与主表 AgentRunbook-R 是同一行，不能混用旧 workflow_b3。
- Source-only→Ours 解释整体事件证据维护；Overlay→Coalesced 解释合并增益。
- 主要目标是降本且保持可用性，不要求准确率上涨；检查更新＋查询，避免成本转移。对 Source-only/公开轻量方法的价值由正式结果检验；它不是扩量门槛，不能只凭对 B3 降本断言独特贡献。
- 不增加 Codex、AgentRunbook-C、MemForest、LightMem 或新数据集；不转向冷构建/自然增长新方法。

## 完成条件
1. Source-only、共同笔记规则和公开更新入口经必要检查及真实运行；实现、配置和论文描述一致。
2. 已有两域各三轮开发比较、四行公开对照、有效独立确认均有可追溯结果（已有相符结果可完成对应阶段，不强制新增）。正式扩量前按协议的两阶段 Manifest 固定数据与最终实现。
3. 完整 Small 历史库的固定维护负载完成，主表四行齐全；Source-only/Overlay 在预先固定的同一核心修订子集比较；Delta Edit 同条件可复用，否则作分版本辅助证据，不要求每个消融重跑全部历史问答。
4. 连续修订成本/证据大小、质量分项、总成本与失败记录齐全；代表案例至少三次配对计时，可复用语义、配置和运行条件相符的已有重复。
5. paper/manuscript.md、paper/reproduction.md 和最终表图完成；主张可追到原始运行。若无独特优势，正文/报告明确贡献不足与负结果，不强行写成正面论文，不把不同版本拼成一个方法。
6. 完整 Small 指完整历史库＋固定修订/问题集合，不等于官方原生全量多模态 QA。小表完成不能代替正式主实验完成。

## 继续工作的规则
先修复明确的实现错误，保证快照、失效、重载、计量和比较协议正确；可评分的答错或 Source-only 持平属于研究结果，不因方法未胜出延迟正式实验。首表后的可选主要候选全程最多两个（允许零个，切换优化对象不重置计数），默认保留可靠 v13 核心，正式冻结后停止性能调优。确认或正式结果用于修改方法时记录暴露与版本；只有明确实现 bug 可做必要修复，并补受影响数据，不声称修复后的同批样本仍为未暴露独立验证。完成全部既定证据后，无论支持优势还是显示贡献不足都可结束本轮。实际外部阻塞不冒充完成。

## 复用与自主权限
按 [复用与自主优化](docs/REUSE_AND_OPTIMIZATION.md) 先核对补缺。哈希用于追溯，不相关变更不强制重跑。Codex 可自主读原始资料、定位瓶颈、实现并配对验证当前方法内的候选，不必等待用户提供 trick。自主权限限于冻结前、最多两个且不延误正式实验的局部候选；正式数据只验证，结果不理想不重开探索。
